# Проверка степеней и делителей

Небольшой скрипт: для каждого числа из диапазона `[от; до]` проверяет,
равно ли `n**степень` произведению всех натуральных делителей `n`.

## Структура
- `check_powers.py` — главный скрипт (точка входа)
- `dividers.py` — функции `get_divisors` (делители за O(√n)) и `prime_factorization`
- `test_dividers.py` — тесты

## Запуск
1. `python check_powers.py`
2. Введите числа по одному в строке: от, до, желаемая степень

## Тесты
`python test_dividers.py` (или `pytest`)
